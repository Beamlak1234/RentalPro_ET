# RentalPro ET

Responsive web shell for Ethiopian rental workflows: tenants, landlords, government officers (separate `/government` entry), and staff admin (`/admin`).

**Stack:** React, TypeScript, Vite, Tailwind CSS v3, Lucide React, React Router.

### Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

`npm run dev` starts the dev server (port from Vite, often 5173). `npm run build` outputs production files to `dist/`.
